# プリセットの書き方

SmartConverter は、プリセットファイル（`Transcoding.ini`）に書いたコマンドを、ファイルごとに上から順に実行します。
携帯動画変換君の `Transcoding.ini` は、書き換えずにそのまま使えます。

プリセットは、GUI の［プリセット編集］（メニューの［ツール］→［プリセット編集］、Ctrl+P）でも作れます。
保存すると、元のファイルは `.bak` として残り、新しいファイルは UTF-8 になります。

## 1. ファイルの形

```ini
[Info]
Title=わたしのプリセット集
Description=説明（省略可）

[Item0]
Title=スマートフォン 720p H.264＋AAC
Command0=""ffmpeg" -y -i "<%InputFile%>" -vf scale=-2:720 -c:v libx264 -crf 23 -c:a aac -b:a 128k "<%OutputFile%>.mp4""

[Item1]
Title=音声だけ AAC
Command0=""ffmpeg" -y -i "<%InputFile%>" -vn -c:a aac -b:a 128k "<%OutputFile%>.m4a""
```

| 項目 | 説明 |
|---|---|
| `[Info]` | プリセット集の名前（`Title`）と説明（`Description`） |
| `[Item0]`、`[Item1]`、… | プリセットです。**0 から連番** で読み、番号が抜けたところで読むのをやめます |
| `Title` | 画面に出るプリセットの名前 |
| `Command0`、`Command1`、… | 実行するコマンドです。**0 から順に 1 つずつ** 実行し、番号が抜けたところで終わります |
| 文字コード | Shift-JIS・UTF-8（BOM の有無を問わない）を自動で判別します。改行は CRLF でも LF でもかまいません |
| 大文字と小文字 | セクション名・キー名は区別しません |
| コメント | `;` で始まる行 |

- 値全体を囲む外側の `"…"` は取り除かれます。`Command0=""ffmpeg" -i …""` は `"ffmpeg" -i …` として実行されます（本家と同じ書き方）。
- `[0Item]` や `[*使わない]` のように形の違うセクションは読み飛ばされるので、プリセットを一時的に外すのに使えます。
- コマンドが 0 以外の終了コードで終わると、そのファイルは「失敗」になり、残りのコマンドは実行しません。

## 2. 置換変数

コマンドの中の `<%名前%>` は、実行の前に次の値に置き換わります。

| 変数 | 値 | 例（入力が `D:\録画\テスト 動画.ts`、出力先が `D:\変換`） |
|---|---|---|
| `<%InputFile%>` | 入力ファイルのフルパス | `D:\録画\テスト 動画.ts` |
| `<%InputFilePath%>` | 入力ファイルのフォルダ（**末尾に区切り文字が付く**） | `D:\録画\` |
| `<%InputFileBase%>` | 入力ファイルの名前（拡張子なし） | `テスト 動画` |
| `<%InputFileExt%>` | 入力ファイルの拡張子（`.` 付き） | `.ts` |
| `<%Title%>` | タイトル＝入力ファイルの名前（拡張子なし）にタイムスタンプを付けたもの | `[03-05] テスト 動画` |
| `<%OutputFile%>` | 出力ファイルのフルパス（拡張子なし）＝出力先＋タイトル | `D:\変換\[03-05] テスト 動画` |
| `<%OutputPath%>` | 出力先のフォルダ（**末尾に区切り文字が付く**） | `D:\変換\` |
| `<%TemporaryFile%>` | 一時ファイルのフルパス（拡張子なし）。ファイルごとに違う名前 | `C:\Users\…\Temp\sc_1234_1_0a1b2c3d4e5f\sc_1234_1_0a1b2c3d4e5f` |
| `<%AppPath%>` | SmartConverter のフォルダ（**末尾に区切り文字が付かない**） | `C:\Tools\SmartConverter` |
| `<%TimeStamp%>` | 入力ファイルの更新日時（書式は `yyyy-mm-dd hh:nn:ss` に固定） | `2024-03-05 07:08:09` |

- `<%OutputFile%>` と `<%TemporaryFile%>` には拡張子が付かないので、コマンドの中で `.mp4` などを付けてください。
- 綴りを間違えた変数（例 `<%OutPutFiel%>`）は、本家と同じく置き換えずにそのまま実行します。ログとプリセット編集画面に警告が出ます。
- Linux ではパスの区切りが `/` になります。
- 同じ名前の出力ファイルがあるときは、オプションの［変換］で「連番を付ける（`名前 (1).mp4`）／上書き／スキップ」を選べます。

### 2.1 タイムスタンプ

オプションの［ファイル名］でタイムスタンプを ON にすると、`<%Title%>` と `<%OutputFile%>` の先頭に入力ファイルの更新日時が付きます。
書式は Delphi の `FormatDateTime` と同じです。

| 書式 | 意味 |
|---|---|
| `yyyy` / `yy` | 年（4 桁 / 2 桁） |
| `mm` / `m` | 月（2 桁 / 1〜2 桁）。`h` の直後では分 |
| `dd` / `d` | 日 |
| `ddd` / `dddd` | 曜日（短い / 長い） |
| `hh` / `h` | 時 |
| `nn` / `n` | 分 |
| `ss` / `s` | 秒 |
| `"…"` / `'…'` | 囲んだ文字をそのまま出す |

ファイル名に使えない文字（Windows の `:` など）は置き換わります。

## 3. 一時ファイル

途中のファイルは `<%TemporaryFile%>.hevc`、`<%TemporaryFile%>.wav` のように、`<%TemporaryFile%>` に拡張子を付けた名前にしてください。
一時ファイルは、ファイルごとに SmartConverter が新しく作るフォルダの中にでき、成功・失敗・中断のどれで終わってもフォルダごと消えます。
本家のプリセットにある `cmd /c del …` の行は要りませんが、残っていても動きます。

一時ファイルの場所は、オプションの［変換］の「一時フォルダ」で変えられます（空なら OS の一時フォルダ）。

## 4. コマンドの解釈と外部ツール

| OS | 解釈 |
|---|---|
| Windows | 先頭のプログラム名だけを取り出し、残りはそのまま渡します（本家と同じなので、既存のプリセットの引用符はそのまま動きます） |
| Linux | POSIX シェルの規則で引数に分けて実行します。シェルは通さないので、`|`・`>`・`&&` を使うときは `sh -c "…"` と書いてください。ファイル名に空白・`"`・`'` などがあっても、変数の値は 1 つの引数の一部として渡ります（必要に応じて SmartConverter がエスケープします） |

プログラムは次の順に探します。

1. `SmartConverter.ini` の `[Tools]`（オプションの［ツール］）に書いた場所（例 `qaac64=C:\tools\qaac\qaac64.exe`）
2. パスを含む名前（`<%AppPath%>\tools\ffmpeg.exe` など）はその場所
3. SmartConverter と同じフォルダと、その `tools` フォルダ
4. （Windows のみ）`C:\Windows\System32`、`C:\Windows`
5. 環境変数 `PATH`

SmartConverter と同じフォルダを PATH より先に探すので、ツールを SmartConverter のフォルダ（または `tools` フォルダ）に置けば、
PATH に入れなくても使えます。そのかわり、SmartConverter は他人が書き込めないフォルダに置いてください
（同じ名前の exe を置かれると、そちらが使われます）。

見つからないときは、実行する前に「ツールが見つかりません」で失敗します。

プリセット例は、配布物の `Transcoding.ini`（`presets/3gpp_aac.ini` と同じもの）です。携帯動画変換君の既定の設定を、今の ffmpeg で書き直したもので、Windows と Linux で同じものを使えます。

## 5. AviSynth+ / VapourSynth のスクリプト

### 5.1 スクリプトを直接変換する

`.avs` / `.vpy` のファイルをそのまま追加すると、それが `<%InputFile%>` になります。
スクリプトを読めるエンコーダ（AviSynth+ / VapourSynth に対応した ffmpeg、QSVEncC など）を使うプリセットを選んでください。

### 5.2 スケルトン（テンプレート）

拡張子ごとにテンプレートを割り当てておくと、その拡張子のファイルを変換するときに、テンプレートからスクリプトを作って入力にします。
オプションの［スクリプト］で設定します（`SmartConverter.ini` では次のとおり）。

```ini
[Script]
Disable=0
Ext0=ts:templates\default.avs
Ext1=mkv:templates\default.vpy
```

- テンプレートの置換変数は、元の入力ファイルで置き換えます（例 `LWLibavVideoSource("<%InputFile%>")`）。
- コマンドの `<%InputFile%>` だけが、作ったスクリプト（`<%TemporaryFile%>.avs` / `.vpy`）に変わります。`<%Title%>` や出力名は元のファイルのままです。
- テンプレートの種類はテンプレートの拡張子で決まります。相対パスは SmartConverter のフォルダから探します。
- AviSynth+ / VapourSynth が見つからない種類のテンプレートは使わず、元のファイルで変換します（ログに警告）。見つかったかどうかはステータスバーに出ます。
- Windows の `.avs` は Shift-JIS で書き出します（AviSynth+ が日本語のパスを読めるように）。`.vpy` と Linux の `.avs` は UTF-8 です。
- `.vpy` では、Windows のパスの `\` がエスケープにならないよう、`r"<%InputFile%>"` のように raw 文字列にしてください。
- テンプレートが使う変数の値に `"` か改行があるとき（Linux のファイル名など）は、安全のためスクリプトを作らずに失敗にします。

配布物の `templates/` に、L-SMASH Works を使う例があります。
