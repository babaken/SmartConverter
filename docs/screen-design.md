## 1. 画面一覧

| ID | 画面 | 形式 | 開き方 |
|---|---|---|---|
| S-01 | メイン | メインウィンドウ | 起動時 |
| S-02 | ログ | 別ウィンドウ | メニュー［表示］→［ログ］、Ctrl+L、ジョブの右クリック→［ログを表示］ |
| S-03 | オプション | 別ウィンドウ（モーダルではない） | メニュー［ツール］→［オプション］、Ctrl+, |
| S-04 | プリセット編集 | 別ウィンドウ | メニュー［ツール］→［プリセット編集］、Ctrl+P |
| S-05 | バージョン情報 | ダイアログ | メニュー［ヘルプ］→［バージョン情報］ |
| D-xx | 確認・エラーダイアログ | ダイアログ | §7 |
| T-01 | トレイメニュー | トレイアイコンの右クリック | 最小化中 |

各ウィンドウは 1 つずつしか開かない（もう一度開く操作をすると、開いているウィンドウを前面に出す）。

## 3. 共通仕様

| 項目 | 仕様 |
|---|---|
| テーマ | OS のライト/ダークに追従（既定）。オプションでライト/ダークに固定できる |
| アクセントカラー | ライト `#0284c7` / ダーク `#38bdf8`（アイコンの青） |
| 状態の色 | 待機＝標準文字色、実行中＝アクセント、完了＝緑 `#16a34a`/`#4ade80`、失敗＝赤 `#dc2626`/`#f87171`、中断・プリセットなし＝橙 `#d97706`/`#fbbf24`（ライト/ダーク） |
| 状態の表示 | 色だけに頼らず、必ず文字（「完了」など）も出す |
| フォント | OS の日本語 UI フォント（基本設計 §9.3）。本文 14px、表 13px、ログは等幅 13px |
| 高 DPI | OS の拡大率に従う。オプションで UI 倍率（80〜200%）を上書きできる |
| ウィンドウ位置 | 閉じたときの位置と大きさを保存して、次回復元する |
| Esc | サブウィンドウ（S-02〜S-05）を閉じる。メイン画面では何もしない |

### 4.2 各部の仕様

| No | 部品 | 仕様 |
|---|---|---|
| ① | プリセット選択 | `Transcoding.ini` の `[ItemN]` のタイトルを順に表示する。ここで選んだプリセットを、**これから追加するファイル** に割り当てる。選択は `DefaultPreset` に保存し、次回の起動時に復元する。プリセットが 0 件のときは「プリセットがありません」と表示し、無効にする |
| ② | 出力先 | テキスト入力（直接編集できる）＋［選択］（フォルダ選択ダイアログ）＋［開く］（OS のファイルマネージャで開く）。存在しないフォルダは赤枠にして、変換開始時に作るかどうかを確認する（D-04）。ドライブのルートは赤枠にして「ドライブのルートには出力できません」と表示する（F-QU-08） |
| ③ | キュー一覧 | 列：#、ファイル（ファイル名のみ。ツールチップでフルパス）、プリセット、状態、進捗（プログレスバー＋「i/N」または %）、経過。複数選択できる（Ctrl / Shift クリック）。列幅は変えられる。ファイルが 0 件のときは、中央に「ここに動画ファイルをドラッグ＆ドロップ」とアイコンを表示する |
| ④ | 実行中の詳細 | 実行中のジョブだけを表示する。ファイル名、「コマンド i/N」とツール名、プログレスバー（進捗が不明なときは左右に動くバー）、経過、予想終了（時刻と残り時間）、予想サイズ。実行中のジョブがなければ「待機中」と表示し、高さはそのまま残す（レイアウトがずれないように） |
| ⑤ | 操作ボタン | ［変換開始］：待機中のジョブがあって、実行中でないときに有効。［処理中を中断］：実行中のときに有効（D-05）。［完了分を消去］：完了したジョブを一覧から消す。［ログ］→ S-02。［設定］→ S-03 |
| ⑥ | ステータスバー | 状態ごとの件数、AviSynth+ / VapourSynth が使えるか（✓ / ✗、ツールチップで検出したパス） |

### 4.3 ドラッグ＆ドロップ

| 状況 | 表示・動作 |
|---|---|
| ドラッグ中（ウィンドウ上） | キュー一覧の全体をアクセント色の破線枠で囲み、「ドロップして追加（N 件）」と表示する |
| ファイルをドロップ | ①で選んでいるプリセットを割り当てて、末尾に `待機` で追加する。「ファイルを追加したらすぐ変換を始める」が ON で、実行中のジョブがなければすぐ始める |
| フォルダが含まれる | フォルダは追加しない。ファイルだけを追加し、画面下部に「フォルダは登録できません（N 件）」と 5 秒間表示する（トースト） |
| 同じファイルがすでに待機中 | 重複して追加する（同じファイルを別プリセットで変換できるようにするため） |

### 4.4 キュー一覧の右クリックメニュー

| 項目 | 有効な条件 | 動作 |
|---|---|---|
| プリセットを変更 ▸ | 選択したジョブがすべて実行中以外 | サブメニューでプリセットを選び、選択したジョブに割り当てる。完了・失敗・中断のジョブは `待機` に戻す |
| 再実行 | 完了・失敗・中断・プリセットなし | `待機` に戻す。「ファイルを追加したらすぐ変換を始める」が ON なら、すぐ変換を始める |
| 上へ / 下へ / 先頭へ / 末尾へ | 待機中 | 実行順を変える（Alt+↑ / Alt+↓） |
| ログを表示 | いつでも | S-02 を開き、そのジョブのログに絞り込む |
| 出力フォルダを開く | 出力名が決まっているジョブ | ファイルマネージャで開く（できれば出力ファイルを選んだ状態で） |
| 入力ファイルの場所を開く | いつでも | 同上 |
| 一覧から削除 | 実行中以外 | 選択したジョブを消す（Delete キー） |

### 4.6 ウィンドウを閉じるとき・最小化

- 実行中のジョブがあるときに閉じようとしたら、D-01 で確認する。
- 「最小化するとトレイに格納する」が ON（トレイが使える環境のみ）なら、最小化でタスクバーから消してトレイに入れる。
- 最小化中・トレイに格納中にジョブが終わったときは、「通知」が ON なら OS の通知を出す（N-03〜N-05。本家のバルーン相当）。開始時は通知しない（数が多くなるため）。

| 部品 | 仕様 |
|---|---|
| 表示 | 「すべてのジョブ」または特定のジョブ（`#2 テスト動画_13.ts` の形式）で絞り込む |
| 検索 | 入力した文字を含む行だけを表示する（大文字・小文字を区別しない） |
| 自動スクロール | ON なら新しい行が来たら末尾に移動する。手動で上にスクロールしたら自動で OFF にする |
| 行の種類 | ━ ジョブ開始（太字）、▶ 実行したコマンド（アクセント色・展開後の全文）、　 ツールの出力（標準色、stderr も同じ）、✓ 成功（緑）、✗ 失敗・中断（赤）、ⓘ アプリからのメッセージ（灰色。例：一時ファイルを削除しました） |
| 進捗行 | `\r` で上書きされる行は、ログでも同じ行を書き換える |
| 行の選択 | クリック、Shift+クリック、Ctrl+クリック。Ctrl+C で選択行をコピー |
| ボタン | ［選択行をコピー］［ログ全体をコピー］（本家互換）、［ファイルに保存…］（UTF-8 のテキスト）、［消去］（表示中のログを消す。実行中のジョブのログは消さない）、［閉じる］ |

既定サイズ 760×480、等幅フォント。

### 7.2 各部の仕様

| 部品 | 仕様 |
|---|---|
| タイトルバー | 編集中のファイル名と、読み込み時の文字コード（保存すると UTF-8 になることを明示） |
| プリセット集の名前・説明 | `[Info]` の `Title` / `Description` |
| プリセット一覧 | `[ItemN]` の順に表示する。［追加］（空のプリセット）［複製］（選択中をコピーして直後に挿入、タイトルに「のコピー」を付ける）［削除］（D-06 で確認）［↑］［↓］（並べ替え）。並び順がそのまま `[Item0]..` の番号になる |
| 保持されるセクション | `[0Item]`、`[*テンプ or ゴミ]` など、プリセットとして読まれないセクションを折りたたんで一覧表示する（読み取り専用）。保存してもそのまま残ることを説明文で示す |
| タイトル | 1 行入力。空やほかのプリセットと重複するときは赤枠にして、保存できない |
| コマンド | 1 行 1 コマンドの入力欄の並び（横幅いっぱい、等幅フォント）。行ごとに［↑］［↓］［✕］。長いコマンドは入力欄の中で横スクロール。※複数行の拡大入力欄（Shift+Enter）は v0.9 では作らない |
| 変数を挿入 | 10 種類の置換変数（要件 §4.3）を、説明付きのメニューから選んでカーソル位置に挿入する |
| 確認（dry-run） | サンプル入力ファイル（既定はキューで選んでいるファイル。なければダミー名）で変数を展開した結果を表示する。下記の警告も出す |
| 未保存の表示 | 変更があれば「● 未保存の変更があります」 |
| ［保存］ | Ctrl+S。`Transcoding.ini.bak` を作ってから UTF-8 で保存する。保存後に S-01 のプリセット一覧へ反映する。タイトルを変えたプリセットは、キューの待機中・終了したジョブとメイン画面の選択も新しいタイトルに付け替える |
| ［元に戻す］ | 最後に保存した状態に戻す（D-07 で確認） |
| ［閉じる］ | 未保存の変更があれば D-08 |

### 7.3 確認欄で出す警告

| 条件 | 表示 |
|---|---|
| 未定義の変数（`<%Foo%>`） | ⚠ 未定義の変数 `<%Foo%>`（置き換えずに文字のまま実行されます） |
| ツールが見つからない | ⚠ `qaac64` が見つかりません（［ツール］設定へのリンク） |
| `cmd /c del` 系の行 | ⓘ 一時ファイルはアプリが自動で削除するため、この行は不要です |
| Linux で `cmd /c` を使っている | ⚠ この行は Windows 専用です |
| コマンドが 0 行 | ✗ コマンドがありません（保存できない） |

### 7.4 外部で変更されたとき

- 編集中に `Transcoding.ini` が外部で変更されたら、画面上部に帯で「ファイルが外部で変更されました ［再読み込み］［このまま編集］」を表示する。
- 未保存の変更がなければ、自動で再読み込みする。
