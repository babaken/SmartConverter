## 1. 目的・背景

「携帯動画変換君」（3GP_Converter, mobilehackerz.jp）は、外部エンコーダ（ffmpeg / QSVEncC / qaac / MP4Box など）を
プリセット定義（`Transcoding.ini`）に従って順番に実行する、ドラッグ＆ドロップ式の動画変換フロントエンドである。
開発が停止しており、Windows 専用・Cygwin 依存・Shift-JIS 固定などの制約がある。

SmartConverter は、その中核機能を **Rust で再実装** し、次を実現する。

- 既存の `Transcoding.ini` のプリセットを **ほぼそのまま** 使い続けられる
- **Windows と Linux** の両方で動く
- INI ファイルを **UTF-8 / Shift-JIS の両方** で扱える

## 2. スコープ

### 2.1 対象（v0.9）
- GUI アプリ（ドラッグ＆ドロップ、プリセット選択、変換キュー、進捗表示、ログ）
- CLI モード（GUI なしで変換を実行）
- `Transcoding.ini` / アプリ設定 INI の読み込み（互換）
- 外部コマンドの順次実行と置換変数の展開
- Windows 10/11（x64）、Linux（x86_64）

### 2.2 対象外
- 全処理終了後のシャットダウン機能（不要と決定）
- 全処理終了後の外部プログラム起動（`ExecIfFinished`。シャットダウン用途が主なので対象外とする）
- エンコーダ本体の実装・同梱（外部ツールはユーザーが用意する）
- iPod / iTunes 連携（`finishing/UpdateiPod(iTunes).exe` 相当）
- 旧版の設定セットアップツール（`[SetupText]` 相当）
- macOS（設計上は妨げないが、v0.9 では動作保証しない）

## 3. 用語

| 用語 | 意味 |
|---|---|
| プリセット | `Transcoding.ini` の `[ItemN]` セクション 1 つ。名前（Title）とコマンド列を持つ |
| ジョブ | 「入力ファイル 1 つ × プリセット 1 つ」の変換単位 |
| キュー | 実行待ち・実行中・完了のジョブの一覧 |
| 置換変数 | コマンド中の `<%Name%>` 形式の文字列。実行時に実際の値に置き換える |

## 4. 機能要件

### 4.1 プリセット定義ファイル（Transcoding.ini）互換

| ID | 要件 |
|---|---|
| F-PR-01 | `[Info]` セクションの `Title`、`Description` を読み込み、プリセット集の名前・説明として表示する |
| F-PR-02 | `[Item0]`, `[Item1]`, … を **0 から連番** で読む。欠番があればそこで読み込みを終える（本家互換。`[0Item]` や `[*テンプ or ゴミ]` のように形式が違うセクションは無視され、「無効化したプリセット」として使える） |
| F-PR-03 | 各プリセットの `Title` と `Command0`, `Command1`, … を **0 から連番** で読む。欠番で終える |
| F-PR-04 | 値全体を囲む外側の `"…"` を取り除く（例: `Command0=""ffmpeg" -i …""` → `"ffmpeg" -i …`） |
| F-PR-05 | 同じセクション内でキーが重複したときは、最初に出てきたものを使う。同じ名前のセクションが複数あるときは、最初のセクションだけを読む。セクション名・キー名は大文字小文字を区別しない（本家で確認済み。[本家動作調査記録](original-behavior.md) §4） |
| F-PR-06 | 起動中に `Transcoding.ini` が更新されたら検知して再読み込みし、そのことを通知する |
| F-PR-07 | 読み込みエラー（構文異常・プリセット 0 件など）は、行番号付きでユーザーに知らせる |

### 4.2 文字コード

| ID | 要件 |
|---|---|
| F-EN-01 | INI 読み込み時に文字コードを自動で判別する：① UTF-8 BOM あり → UTF-8 ② 内容が UTF-8 として正しい → UTF-8 ③ それ以外 → Shift-JIS（CP932） |
| F-EN-02 | 改行コードは CRLF / LF の両方を受け付ける |
| F-EN-03 | アプリが INI を保存するときは UTF-8（BOM なし）・その OS 標準の改行で書く（Shift-JIS で読み込んだファイルも UTF-8 で保存する） |
| F-EN-04 | 外部コマンドの標準出力・標準エラー出力も、UTF-8 / CP932 を自動で判別して表示する（Windows のコンソールツール対策） |

### 4.3 置換変数

| 変数 | 意味 | 本家 |
|---|---|---|
| `<%InputFile%>` | 入力ファイルのフルパス | ○ |
| `<%InputFilePath%>` | 入力ファイルのフォルダ（末尾に区切り文字が付く） | ○ |
| `<%InputFileBase%>` | 入力ファイル名（拡張子なし） | ○ |
| `<%InputFileExt%>` | 入力ファイルの拡張子（`.` 付き。例 `.ts`） | ○ |
| `<%OutputFile%>` | 出力ファイルのフルパス（拡張子なし）＝ 出力先フォルダ ＋ タイトル | ○ |
| `<%OutputPath%>` | 出力先フォルダ（末尾に区切り文字が付く） | ○ |
| `<%Title%>` | タイトル ＝ 入力ファイル名（拡張子なし）にタイムスタンプ設定を反映したもの | ○ |
| `<%TemporaryFile%>` | 一時ファイルのフルパス（拡張子なし）。ジョブごとに一意 | ○ |
| `<%AppPath%>` | SmartConverter 実行ファイルのフォルダ（末尾に区切り文字が **付かない**） | ○ |
| `<%TimeStamp%>` | 入力ファイルの更新日時。書式は `yyyy-mm-dd hh:nn:ss` に固定（タイムスタンプ設定とは無関係） | ○ |

本家の調査結果は [本家動作調査記録](original-behavior.md) を参照。

| ID | 要件 |
|---|---|
| F-VA-01 | 未定義の変数（例 `<%OutPutFiel%>`）は本家と同じく置き換えず、文字のまま実行する。ただしログに「未定義の変数 `<%OutPutFiel%>`」と警告を出し、プリセット編集画面でも警告する |
| F-VA-02 | パス区切りは実行中の OS に合わせる。末尾に区切り文字が付く・付かないは本家と同じにする |

### 4.4 コマンド実行

| ID | 要件 |
|---|---|
| F-EX-01 | プリセットの `Command0` から順に、1 つずつ同期実行する |
| F-EX-02 | Windows：展開後の文字列をコマンドラインとしてそのまま渡す（`CreateProcess` 相当。本家と同じ引用規則）。Linux：POSIX シェルの単語分割規則で argv に分解して実行する（シェルは経由しない） |
| F-EX-03 | 終了コードが 0 以外ならジョブを失敗にし、そのジョブの残りのコマンドは実行しない |
| F-EX-04 | 子プロセスはコンソールウィンドウを表示しない（Windows） |
| F-EX-05 | 子プロセスの優先度を設定で選べる：0 アイドル（推奨・既定）／1 通常／2 高／3 リアルタイム（非推奨）。Linux では nice 値に対応付ける（リアルタイムは選べないか、通常の上限に丸める） |
| F-EX-06 | 外部ツールは PATH から探す。加えて「ツール名 → パス」の対応を設定で上書きできる（OS 別プリセットの差分を小さくするため） |
| F-EX-07 | ジョブ終了時（成功・失敗・中断のどれでも）、`<%TemporaryFile%>` で始まる一時ファイルをアプリが自動で削除する。これで `cmd /c del …` のような OS 依存のコマンドが要らなくなる。既存プリセットの `cmd /c del` 行は残っていても動く（Windows） |
| F-EX-08 | 一時ファイルの場所は設定 `TemporaryFolder` に従う。未指定なら OS の一時ディレクトリを使う |

### 4.5 キュー・ジョブ管理

| ID | 要件 |
|---|---|
| F-QU-01 | ファイル（複数可）をドラッグ＆ドロップするとキューに追加される。フォルダをドロップした場合は登録せず、ログに「フォルダは登録できません」と出す |
| F-QU-02 | ジョブはプリセットを持つ。追加時点で選ばれていたプリセットを割り当て、実行前なら変更できる |
| F-QU-03 | 状態を表示する：待機／実行中／完了／失敗／中断 |
| F-QU-04 | 選んだジョブをキューから削除できる（実行中は除く） |
| F-QU-05 | 「処理中のファイルを中断」ボタン。設定 `AllAbort` が有効なら、キュー全体の処理も止める。中断したジョブの途中までの出力は、設定 `DeletePartial`（既定 ON）なら消す（そのジョブで新しくできたファイルだけ。上書きしたファイルは元に戻せないので残す） |
| F-QU-06 | 中断すると子プロセス（とその子孫）を終了させる（Windows は Job Object、Linux はプロセスグループ） |
| F-QU-07 | 順次実行のみとする（同時に実行するジョブは 1 つ）。並列実行は行わない |
| F-QU-08 | ドライブのルート（例 `D:\`、Linux の `/`）は出力先にできない（本家互換）。設定時と変換開始時の両方で確認し、エラーにする |
| F-QU-09 | 本家にあった「ネットワークドライブのファイルは追加できない」制限は **設けない** |
| F-QU-10 | 出力ファイルがすでにあるときの扱い（上書き／連番を付ける／スキップ）を設定で選べる。既定は連番 |

### 4.6 進捗・ログ

| ID | 要件 |
|---|---|
| F-PG-01 | 処理中ジョブの経過時間を表示する |
| F-PG-02 | 外部ツールの出力から進捗率を解析し、予想終了時刻・予想ファイルサイズを表示する。最低限 ffmpeg、QSVEncC / NVEncC 系に対応する。解析できないツールは「不明」表示にして、経過時間だけを出す |
| F-PG-03 | ジョブ全体の進捗は「コマンド i / N」と、そのコマンドの進捗率で表す |
| F-PG-04 | ログウィンドウ：展開後の実行コマンド、標準出力・標準エラー出力、終了コードを時刻付きで表示する。「選択行をコピー」「ログ全体をコピー」ができる |
| F-PG-05 | ログはファイルにも保存できる（設定で有効・無効を切り替え） |

### 4.7 ファイル名・タイムスタンプ

| ID | 要件 |
|---|---|
| F-FN-01 | 出力ファイル名（`<%OutputFile%>` と `<%Title%>`）にタイムスタンプを付けられる（`AddTime`）。位置（`AddTimePos`）は 0＝先頭（1 字空け）、2＝先頭（空けない）。本家と同じく **末尾（1・3）は付けない**（本家でも付かない。INI に 1・3 があっても読み込めるが何も付けない）。画面の選択肢は先頭の 2 種だけにする |
| F-FN-02 | 書式（`AddTimeFormat`）は Delphi の `FormatDateTime` 互換（基本設計 §8.2）。画面には本家と同じ 6 つの候補を出し、自由入力もできる。基準は入力ファイルの更新日時（ローカル時刻）。秒は丸めず実際の値を使う（本家は 2 秒単位に切り上げていたが、合わせない。`<%TimeStamp%>` も同じ） |
| F-FN-03 | 設定画面でサンプルのファイル名をその場で表示する |
| F-FN-04 | ファイル名に使えない文字は、OS に合わせて置き換える |

### 4.8 アプリ設定（3GP_Converter.ini 互換）

| 本家キー | SmartConverter | 備考 |
|---|---|---|
| `OutputDir` | ○ | 出力先ディレクトリ |
| `DefaultSetitng` | ○ | 起動時に選ばれるプリセット（本家の綴り誤りも読めるようにする） |
| `ExePriority` | ○ | F-EX-05 |
| `ExitIfFinished` | ○ | 全ジョブ完了で自動終了 |
| `Minimized` | ○ | 最小化（トレイ）状態で起動 |
| `EncodeBalloon` | ○ | 処理中・完了を OS の通知で知らせる |
| `AllAbort` | ○ | F-QU-05 |
| `AddTime` / `AddTimePos` / `AddTimeFormat` | ○ | §4.7 |
| `TemporaryFolder` | ○ | F-EX-08 |
| `DisableAVS`, `[Avisynth]` | ○ | §4.10（.vpy にも拡張） |
| `Language` | ○ | §4.11 |
| `ExecIfFinished` / `ExecIfFinishedCmd` | × | 対象外 |

| ID | 要件 |
|---|---|
| F-ST-01 | 設定ファイルは SmartConverter 独自の `SmartConverter.ini`（UTF-8）を正とする |
| F-ST-02 | 初回起動時に本家 `3GP_Converter.ini` を指定すると、設定を取り込める（インポート） |
| F-ST-03 | 設定ファイルの置き場所：実行ファイルと同じ場所に設定ファイルがあればそこ（ポータブル）。なければ、Windows は実行ファイルと同じ場所に書き込めればそこ、書き込めなければ `%APPDATA%`。Linux は `$XDG_CONFIG_HOME`（既定 `~/.config`）（v1.0 に向けて変更） |
| F-ST-04 | 設定は GUI の「オプション」画面で編集できる |

### 4.9 CLI モード

| ID | 要件 |
|---|---|
| F-CL-01 | `smartconverter-cli -i <入力> -p <N> -o <出力先フォルダ>` で GUI を表示せず変換する（例 `smartconverter-cli -i XXXX.ts -p 001 -o /test/001`） |
| F-CL-02 | `-p <N>`：`[ItemN]` の N でプリセットを指定する（0 始まり。`001` のように先頭に 0 があってもよく、`001` は `[Item1]`） |
| F-CL-03 | `-S "<タイトル>"`：タイトルでプリセットを指定する（本家の `-S` 互換）。`-p` と `-S` は同時に指定できない。どちらもなければ設定の `DefaultPreset` を使う |
| F-CL-04 | `-o <フォルダ>`：出力先フォルダ。出力ファイル名は入力ファイル名から決める（`/test/001/XXXX.mp4`）。フォルダがなければ作る。ドライブのルートは指定できない。省略時は GUI で設定した出力先フォルダ（GUI と共通の `SmartConverter.ini` の `OutputDir`）に出力する |
| F-CL-05 | `-i <入力>`：入力ファイル。`-i` を繰り返すか、オプションの後ろにファイルを並べて複数指定できる（`-S` 互換の書き方）。Windows ではワイルドカード（`*.ts`）をアプリ側で展開する。フォルダは指定できない |
| F-CL-06 | `--list-presets`：プリセット一覧を「N とタイトル」で表示する |
| F-CL-07 | `--ini <path>`：使う `Transcoding.ini` を指定する |
| F-CL-08 | `--dry-run`：展開後のコマンドを表示するだけで、実行しない |
| F-CL-09 | 設定の上書き：`--on-exists <rename\|overwrite\|skip>`、`--priority <0-3>`、`--temp-dir <path>`、`--config <SmartConverter.ini のパス>` |
| F-CL-10 | 表示：端末（TTY）ではプログレスバーを表示する（全体：何ファイル目か／現在のファイル：進捗率・フレーム数・速度・経過・残り時間）。ffmpeg はフレーム数から進捗率を計算する（基本設計 §7.1）。パイプやリダイレクト先が端末でないときは、プログレスバーの代わりに 10 秒ごとに進捗を 1 行で出す。`-q` で進捗を出さない。`-v` で外部ツールの出力もそのまま流す。`--log <file>` でログをファイルに保存する |
| F-CL-11 | 終了コード：全成功 0／一部失敗 1／設定・引数エラー 2／中断（Ctrl+C）130 |
| F-CL-12 | Ctrl+C で実行中の外部ツールも含めて止め、一時ファイルを削除してから終了する |

### 4.10 AviSynth / VapourSynth スクリプト対応

| ID | 要件 |
|---|---|
| F-AV-01 | `.avs`（AviSynth）と `.vpy`（VapourSynth）のスクリプトを入力ファイルとして受け付ける。`<%InputFile%>` にはスクリプトのパスが入り、読み込みはプリセット側のエンコーダが行う（例: QSVEncC の `--avs` / `--vpy`、ffmpeg の avisynth / vapoursynth 入力） |
| F-AV-02 | スケルトン機能（本家互換）：拡張子ごとにテンプレートの `.avs` / `.vpy` を設定しておくと、そのテンプレート内の `<%InputFile%>` を展開したスクリプトを一時ファイルとして作り、それを `<%InputFile%>` としてプリセットを実行する |
| F-AV-03 | テンプレートの割り当ては拡張子ごとに設定する（本家 `[Avisynth]` の `ExtN=拡張子:テンプレートパス` を読み込める）。`.vpy` のテンプレートも同じ形式で指定できる |
| F-AV-04 | スケルトン機能全体を無効にできる（本家 `DisableAVS` 互換） |
| F-AV-05 | 起動時に AviSynth+ / VapourSynth が使えるかを調べて表示する。使えないときは F-AV-02 を自動で無効にする。F-AV-01 はエンコーダ側の判断に任せる |
| F-AV-06 | Windows・Linux の両方で対応する（AviSynth+ と VapourSynth はどちらも Linux 版がある）。本家テンプレートの `DirectShowSource` などの Windows 専用関数は、Linux では使えない旨をドキュメントに書く |
| F-AV-07 | 生成したスクリプトは F-EX-07 と同じタイミングで削除する |

## 5. 画面要件（概要）

```
┌ SmartConverter ─────────────────────────────────────┐
│ プリセット: [ QVGA標準画質15fpsステレオ         ▼ ]  │
│ 出力先:     [ D:\Videos\Mobile             ] [選択]  │
├──────────────────────────────────────────────────────┤
│  ここにファイルをドラッグ＆ドロップ                   │
│  ┌──────────────┬──────────────┬────────┬────────┐   │
│  │ ファイル      │ プリセット     │ 状態    │ 進捗    │   │
│  ├──────────────┼──────────────┼────────┼────────┤   │
│  │ ep13.ts      │ QVGAステレオ │ 実行中  │ 2/4 63% │   │
│  │ ep11.ts      │ QVGAステレオ │ 待機    │        │   │
│  └──────────────┴──────────────┴────────┴────────┘   │
├──────────────────────────────────────────────────────┤
│ 経過 00:03:12  予想終了 16:42  予想サイズ 182MB       │
│ [変換開始] [処理中を中断] [ログ] [オプション]          │
└──────────────────────────────────────────────────────┘
```

- メイン画面、ログウィンドウ、オプション画面の 3 つ
- タスクトレイ（Linux は対応環境のみ）。最小化時はトレイに格納する
- 高 DPI に対応する。日本語フォントを確実に表示する（フォントの同梱または OS フォントの読み込み）

## 6. 非機能要件

| ID | 区分 | 要件 |
|---|---|---|
| N-01 | 言語 | Rust（stable、edition 2021 以降） |
| N-02 | 配布 | 単体の実行ファイル（Windows は `.exe`、Linux はバイナリ。AppImage は任意）。ランタイムの別途インストールは不要 |
| N-03 | 依存 | Cygwin・.NET など、本家が依存していたものを必須にしない。AviSynth+ / VapourSynth は任意（入っていればスクリプト機能を使える） |
| N-04 | 性能 | 起動は 1 秒以内が目安。アイドル時の CPU 使用率はほぼ 0 |
| N-05 | 堅牢性 | 外部ツールの異常終了・ハングで GUI が固まらない（実行は別スレッド） |
| N-06 | パス | 日本語・空白・長いパス（Windows の 260 文字超）を含むファイルを扱える |
| N-07 | 安全性 | プリセットのコマンドはユーザーが書いたものとして実行する。プリセットの出所が信頼できない場合の注意をドキュメントに書く |
| N-08 | テスト | INI パーサ、文字コード判別、変数展開、引数分割は単体テストを用意する。既存の `Transcoding.ini` を使った互換テストを行う |
| N-09 | ライセンス | MIT OR Apache-2.0（デュアルライセンス） |

## 7. OS 差異の扱い

| 項目 | Windows | Linux |
|---|---|---|
| コマンドラインの解釈 | CreateProcess にそのまま渡す | POSIX の単語分割で argv にする |
| 一時ファイル削除 | アプリが自動で削除（`cmd /c del` 不要） | 同左 |
| 優先度 | `SetPriorityClass` | `nice` |
| プロセスツリーの終了 | Job Object | プロセスグループ（`killpg`） |
| qaac | 使える | 使えない。fdkaac / ffmpeg（aac）に置き換えるか、wine 経由にする（プリセット側で対応） |
| QSVEncC | 使える | Linux 版を使う（Intel GPU とドライバが必要） |
