# 本家（携帯動画変換君 0.34）動作調査記録

| 項目 | 内容 |
|---|---|
| 調査日 | 2026-11-02 |
| 対象 | 本家 0.34 の `3GP_Converter.exe`（作業用フォルダにコピーして実行。元のフォルダは変更していない） |
| 方法 | ① UPX で展開したコピーから文字列を抽出 ② 置換変数の展開結果をファイルに書き出すだけのテスト用プリセットを作り、`3GP_Converter.exe -S "TEST" <ファイル>` で実行 |
| 入力ファイル | `テスト 動画.ts`（更新日時 2024-03-05 07:08:09 などに設定） |

本家は Delphi 製（`EIniFileException`、`IniFiles` などの文字列から判断）。

## 1. 置換変数（全 10 種類）

実行ファイル内の文字列から 10 種類を確認し、すべて実際に展開して値を確かめた。

| 変数 | 展開例 | 説明 |
|---|---|---|
| `<%InputFile%>` | `C:\…\in\テスト 動画.ts` | 入力ファイルのフルパス |
| `<%InputFilePath%>` | `C:\…\in\` | 入力ファイルのフォルダ（**末尾に `\` が付く**） |
| `<%InputFileBase%>` | `テスト 動画` | 入力ファイル名（拡張子なし） |
| `<%InputFileExt%>` | `.ts` | 入力ファイルの拡張子（**`.` 付き**） |
| `<%OutputFile%>` | `C:\…\out\[03-05] テスト 動画` | 出力ファイルのフルパス（拡張子なし）。タイムスタンプが付く |
| `<%OutputPath%>` | `C:\…\out\` | 出力先フォルダ（**末尾に `\` が付く**） |
| `<%Title%>` | `[03-05] テスト 動画` | タイトル ＝ 出力ファイル名（拡張子なし）。タイムスタンプが付く |
| `<%TemporaryFile%>` | `C:\Users\…\AppData\Local\Temp\6489ACCC-A34D2C8A-887A5327-8704549C` | 一時ファイル（拡張子なし）。OS の一時フォルダに、16 進 8 桁 × 4 の名前 |
| `<%AppPath%>` | `C:\…\orig` | 実行ファイルのフォルダ（**末尾に `\` が付かない**） |
| `<%TimeStamp%>` | `2024-03-05 07:08:10` | 入力ファイルの更新日時。書式は **`yyyy-mm-dd hh:nn:ss` に固定**（タイムスタンプ設定とは無関係で、常に展開される） |

- 知らない変数（例 `<%OutputDir%>`）は **展開されず、文字列のまま** コマンドに渡る。

## 2. タイムスタンプ

### 2.1 書式

Delphi の `FormatDateTime` の書式がそのまま使える。GUI の候補一覧（実行ファイル内の文字列）は次の 6 つ。

| 候補 | 例（2024-03-05 07:08:10） |
|---|---|
| `[mm-dd]` | `[03-05]` |
| `[mm-dd hh-mm]` | `[03-05 07-08]`（`hh` の直後の `mm` は「分」になる） |
| `[yy-mm-dd]` | `[24-03-05]` |
| `[yy-mm-dd hh-mm]` | `[24-03-05 07-08]` |
| `[yy-mm-dd hh-mm-ss]` | `[24-03-05 07-08-10]` |
| `[yyyymmdd]` | `[20240305]` |

候補以外の書式も INI に書けば使える。例：`yyyy_mm_dd(ddd) hh_nn_ss` → `2024_03_05(火) 07_08_10`（`ddd` は日本語の曜日、`nn` は分）。

### 2.2 位置（AddTimePos）

| 値 | 画面の表示 | 結果（`[mm-dd]`） |
|---|---|---|
| 0 | ファイル名/タイトルの先頭（1字あけ） | `[03-05] テスト 動画` |
| 1 | ファイル名/タイトルの末尾（1字あけ） | `テスト 動画`（**付かない**） |
| 2 | ファイル名/タイトルの先頭 | `[03-05]テスト 動画` |
| 3 | ファイル名/タイトルの末尾 | `テスト 動画`（**付かない**） |

- **末尾（1 と 3）は本家では動かない**（バグとみられる）。
- 付ける対象は `<%OutputFile%>` と `<%Title%>` の両方。`<%InputFileBase%>` には付かない。
- `AddTime=0` のときはどの位置でも付かない。

### 2.3 秒の丸め

更新日時は **2 秒単位に切り上げ** られる（FAT / DOS 形式の日時を経由しているとみられる）。

| 実際の更新日時 | 本家での値 |
|---|---|
| 07:08:08 | 07:08:08 |
| 07:08:09 | 07:08:10 |
| 07:08:11 | 07:08:12 |
| 07:08:59 | 07:09:00 |
| 2024-03-05 23:59:59 | **2024-03-06** 00:00:00（日付も繰り上がる） |

## 3. 設定ファイル（3GP_Converter.ini）のキー

実行ファイル内で確認したキー：`Language`、`OutputDir`、`DefaultSetitng`（綴りは本家のまま）、`ExePriority`、`ExitIfFinished`、`DisableAVS`、`Minimized`、`EncodeBalloon`、`TemporaryFolder`、`AllAbort`、`AddTime`、`AddTimePos`、`AddTimeFormat`、`ExecIfFinished`、`ExecIfFinishedCmd`、`[Avisynth]` の `ExtN`。

## 4. INI の読み方とコマンドの失敗（追加調査）

テスト用のプリセットで確認した。

| 項目 | 結果 |
|---|---|
| セクション名（`[item0]`） | 大文字小文字を区別しない |
| 置換変数名（`<%inputfile%>`、`<%TITLE%>`） | 大文字小文字を区別しない |
| キーの前後の空白（`Command1 = …`） | 取り除かれる |
| 値の前後の空白（`Title=  TEST  `） | 取り除かれる |
| 同じキーが 2 回（`Title=` が 2 行） | 最初の行が使われる |
| 同じ名前のセクションが 2 つ | 最初のセクションだけが読まれる（2 つ目にだけある `Command5` は実行されない） |
| 値の全体が `'…'` で囲まれている | 外側の `'` が外される（`"…"` と同じ） |
| 終了コードが 0 以外のコマンド（`cmd /c exit 3`） | **そこで止まり、残りのコマンドは実行されない** |

これらは Windows の GetPrivateProfileString と同じ動作。SmartConverter の `ini` モジュールも同じ読み方にした。

## 5. その他

- `-S "タイトル" ファイル` で起動すると、GUI を開いてすぐ変換を始める。`ExitIfFinished=1` なら終わったら終了する（終了コード 0）。
- コマンドは `cmd /c` を経由せず直接起動されるので、`<%…%>` の展開後に cmd を使う場合は、cmd の環境変数展開（`%Date%` など）が別に起こる点に注意する。

## 6. スケルトン機能

調査用のコピー（作業用フォルダ）で、`[Avisynth]` に `Ext0=TS:\cores\probe.avs`、`DisableAVS=0` を設定し、
置換変数をすべて書いたテンプレートで `-S` 起動して確かめようとした。

| 確認したこと | 結果 |
|---|---|
| 同梱の `cores\avscheck.exe` が無い状態（利用者の環境では `avscheck.exe-old` に名前が変えてある） | スケルトンは使われず、元のファイルがそのまま `<%InputFile%>` になった。AviSynth の有無を `avscheck.exe` で調べ、見つからなければスケルトン機能を使わないとみられる |
| `avscheck.exe` を元の名前に戻した状態（AviSynth+ 3.x の 64 ビット版が入った Windows 11） | `avscheck.exe`（Cygwin 製）が自分自身を起動し続けて止まらず（数百個）、本家は変換を始めなかった。プロセスを止めて調査を中止 |

- このため、テンプレート内でどの置換変数が展開されるかは本家で確かめられなかった。SmartConverter では、テンプレート内の置換変数を
  すべて元の入力ファイルで展開し、コマンド側は `<%InputFile%>` だけを生成したスクリプトに差し替える（[基本設計](basic-design.md) §4.3）。
- 有無の確認は `avscheck.exe` を使わず、ライブラリのファイルがあるかで判断する。
- 本家同梱のテンプレート（`AVS_Skelton.avs` など）は `DirectShowSource` を使うので Windows 専用。Windows の SmartConverter では
  そのまま使える（Shift-JIS のテンプレートから、日本語のパスを含むスクリプトを作って変換できることを確認）。
